Scan to install Zone

Open your phone's camera, point it at the code. Android only — see below for iPhone.

zone-thezone.vercel.app

Install steps

  1. Scan the code, or open the link above. Tap Get the app.
  2. Chrome downloads the file, then shows "Install unknown apps?" or "This type of file can harm your device." Tap Settings, turn on Allow from this source, then go back and tap the file again. (Only asked once per phone.)
  3. Tap Install, then Open. Pick a role — Citizen, Responder, or Map — and allow Bluetooth + Location when asked.

iPhone can't run the mesh (Apple blocks the Bluetooth broadcast this needs) — open the link in Safari instead for the live map and control-room view.
